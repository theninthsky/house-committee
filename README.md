# ניהול ועד בית (House Committee)

אפליקציית web לניהול כספי ועד בית: גבייה מדיירים, קבלות, ספקים והוצאות, קופה קטנה, התאמות בנק ודוחות.
אתר סטטי לחלוטין (React + Vite), ללא שרת. כל הנתונים נשמרים בדפדפן של המשתמש (IndexedDB).

## הרצה מקומית

```bash
npm install
npm run dev
```

## פריסה ל-Cloudflare Pages

- **Build command:** `npm run build`
- **Build output directory:** `dist`
- **Node version:** 18 ומעלה

הניתוב מבוסס `#` (hash), כך שאין צורך בהגדרות הפניה (redirects).
הקובץ `public/_headers` דואג שה-service worker יתעדכן מיד אחרי כל פריסה.

## אפליקציה מותקנת (PWA)

- במחשב (Chrome / Edge): כפתור "התקנת האפליקציה" בתחתית התפריט, או אייקון ההתקנה בשורת הכתובת.
- באנדרואיד: תפריט הדפדפן ← "התקנת אפליקציה".
- באייפון (Safari): כפתור השיתוף ← "הוספה למסך הבית".
- אחרי ההתקנה המערכת עובדת גם בלי אינטרנט. כשיוצאת גרסה חדשה מופיע באנר "עדכון עכשיו".
- האייקונים נוצרים מ-`scripts/generate-icons.mjs`. אחרי שינוי בעיצוב מריצים `npm run icons`.
- הנתונים נשמרים לפי כתובת האתר: אפליקציה מותקנת ואותו אתר בדפדפן חולקים את אותם נתונים.

## מה יש במערכת

| מודול | מסך |
|---|---|
| לוח בקרה: יתרות, סטטוס גבייה, התראות, פעולות מהירות | `#/` |
| מטריצת גבייה (11 דירות × 12 חודשים) + חיובים מיוחדים | `#/collection` |
| כרטיסי דיירים, היסטוריית תעריפים, כרטסת דייר | `#/units` |
| תקבולים, קבלות ממוספרות (PDF / וואטסאפ / מייל), צ'קים דחויים | `#/payments` |
| הוצאות עם צירוף חשבוניות סרוקות | `#/expenses` |
| ספקים קבועים ומזדמנים, הוראות קבע אוטומטיות, תוקף חוזים | `#/vendors` |
| קופה קטנה, משיכות והפקדות, ספירת קופה | `#/cash` |
| כרטסת תנועות עם סינון וחיפוש | `#/ledger` |
| ייבוא דף בנק (Excel / CSV) והתאמה חצי-אוטומטית | `#/bank` |
| דוחות: רווח והפסד, חייבים, כרטסת דייר, ספקים, קופה קטנה (PDF + Excel) | `#/reports` |
| הגדרות, נעילת שנים, גיבוי ושחזור, יומן פעולות | `#/settings` |

## חשוב לדעת: איפה הנתונים נשמרים

- הנתונים נשמרים **רק בדפדפן שבו עובדים**. דפדפן אחר או מחשב אחר לא יראו אותם.
- **גיבוי:** הגדרות ← גיבוי ושחזור. אפשר להוריד קובץ גיבוי (כולל הקבצים הסרוקים), או לבחור תיקייה שמסונכרנת לענן (למשל Google Drive) לגיבוי יומי אוטומטי (Chrome / Edge).
- מעבר למחשב אחר: גיבוי במחשב הישן ← שחזור במחשב החדש.
- ניקוי נתוני הגלישה בדפדפן מוחק גם את נתוני המערכת. לכן חשוב לגבות.

## מגבלות של אתר סטטי

- **שליחת קבלות:** כפתור "שיתוף" פותח את חלון השיתוף של המכשיר (בטלפון: וואטסאפ/מייל עם ה-PDF מצורף). במחשב שלא תומך בכך, ה-PDF יורד ונפתח וואטסאפ / מייל עם טקסט מוכן, ואת הקובץ מצרפים ידנית.
- **גישת דיירים:** אין התחברות לדיירים. אפשר לשלוח לדייר מצב חשבון בוואטסאפ, או להפיק עבורו כרטסת אישית כ-PDF.
- **יומן פעולות:** מתעד את שם "המשתמש הנוכחי" שהוגדר במחשב, בלי אימות זהות.
